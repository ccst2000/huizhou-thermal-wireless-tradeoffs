## v1.2.0 — v4 analysis chain (post-revision)

Corresponds to the revised manuscript (v4). Superseded v3 scripts/data retained under `code/legacy_v3/` and `data/legacy_v3/`.

**Analysis chain**
- Wireless: four-phase grid aggregation with 3-D-distance NLOS truncation as the default model (`s20b_coverage_v4.py`); un-truncated variant retained as sensitivity; 700-MHz four-phase sensitivity unchanged.
- Thermal: overpass-matched ΔLST with bootstrap CIs (seed=7, B=10000) plus village-absolute summer LST from a de-duplicated composite (`s56_thermal_v4.py`, `s59_lst_composite_v4.py`).
- Statistics: `s41d_stats_v4.py` — FDR-controlled families, partial correlations, Moran's I (999 permutations), Fisher CIs, jackknife and sensitivity batteries; all manuscript numbers regenerated into `data/stats_v4.json`.
- Figures 1–5 regenerated by `s42_fig1_v4.py`, `s23_fig234_v4.py`, `s22_fig5_v4.py`.

**Morphology-table audit (new)**
- `s10_morph_terrain.py`: fully scripted re-implementation of the morphology/terrain metrics from public rasters (COP-DEM, WorldCover). Rank agreement with the published table: Spearman ρ = 0.84–0.98 on elevation/relief/slope/sky-view-factor/forest-ring/water proximity.
- `s61_morph_robustness.py` + `tables/TableA13_morph_robustness.csv`: substituting the re-implemented metrics into the analysis table preserves the sign of all 18 headline correlations — conclusions are rank-robust to the morphology-chain implementation.
- `README.md` now carries an honest provenance statement for `data/morphology_table.csv`.

**Reproducibility tooling**
- `CHECKSUMS.sha256` — SHA-256 for all 51 CSVs in `data/` and `tables/` (verified OK).
- `run_all.py` — one-command pipeline runner, skips existing products.
- `s60_unit_tests.py` — unit tests of geometry/metric primitives.
- Fixed seeds documented: s56 bootstrap seed=7 (B=10000); s41d seed=11 (B=2999), Moran 999 permutations.
